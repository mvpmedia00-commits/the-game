# MVP Media: Las Vegas — How the Code Works

This document explains the code behind the game: how the files are organized, what each one does, and the main formulas. For what the game *is* (story, characters, missions, controls), read [GAME.md](GAME.md). For the store page copy, read [STORE.md](STORE.md).

---

## 1. The big picture

- **Language:** plain JavaScript (ES modules). There is **no build step**: no npm install, no bundler. The browser loads the files directly.
- **3D engine:** [Three.js](https://threejs.org) version 0.160, loaded from the jsDelivr CDN through an *import map* in each `index.html`.
- **Everything is made in code:** the city, the cars, the people and their textures (windows, signs, asphalt, tattoos) are generated by JavaScript at load time. The only image files are the ones you add yourself (character models).
- **Saving:** the browser's `localStorage`, under the key `mvp_world_v2`.
- **Runs on:** Chrome, Safari, Edge and Firefox on desktop, plus iPhone and Android (touch controls appear automatically).

To run it locally, serve the repo folder with any static web server (for example `npx serve .`) and open `/world/`. Opening the HTML file directly from disk won't work, because browsers block ES modules on `file://`.

## 3. How a frame runs (`world/main.js`)

The game is one loop that runs about 60 times a second:

```
frame()
 └─ update(dt)            dt = seconds since last frame (capped at 0.05)
     1. Clock: 2 game-minutes per real second. Midnight → new day → royalties paid.
     2. First launch: Tony's phone call (mission 1) plays automatically.
     3. Input: keyboard + touch joystick → forward/right amounts.
     4. Driving?  → PlayerCar.update() moves the car, engine sound follows speed.
        On foot?  → moveChar() walks/runs MVP, collision, walk animation.
     5. updateNPCs(): puts each story character in the right scene and pose.
     6. updMission(): timers, "reached the spot?", chase damage, escape check.
     7. World only: traffic, pedestrians, neon animation, moon shadow follows you,
        zone name ("Crown Casino", "The Strip"...).
     8. springs.update(): hair/skirt/earring physics.
     9. interaction(): finds the nearest thing you can do → shows the "E" prompt.
    10. Camera: over-the-shoulder on foot, chase cam in the car; pulled in so it
        never goes through walls; shakes on crashes.
    11. Objective beacon, minimap, timer, rule-of-thirds grid.
 └─ composer.render()     draws the frame with bloom
```

### Rendering setup
- `WebGLRenderer` with ACES filmic tone mapping and soft shadows. Pixel ratio is capped (1.5 on phones, 1.75 on desktop) to keep it smooth.
- **Post-processing:** `RenderPass` → `UnrealBloomPass` (strength 0.65, radius 0.5, threshold 0.9: only very bright things glow, like neon) → `OutputPass`.
- **Three scenes** in the `SC` table: `world` (the city), `studio` (MVP Studios), `club` (The Velvet Room). Going through a door fades to black, swaps which scene is drawn, and moves MVP in.
- **Lighting the city:** a gradient sky dome, 1,500 stars, night fog, a hemisphere fill light, and a moonlight that casts shadows. A tiny "neon panels" scene is turned into an environment map so shiny surfaces (car paint, wet road) reflect pink, teal and amber.
- **Interiors** use Three's `RoomEnvironment` for reflections. The studio's lights are scaled ×π×4 because r160 uses real-world light units.

### Directions and coordinates
- 1 unit = 1 metre. **x = east, z = south.** Las Vegas Blvd runs along z, Fremont Ave along x, and they cross at (0, 0).
- A character's heading `a` means "forward = (sin a, cos a)". The car model is built facing +x, so it's rotated by `atan2(-cos a, sin a)`.

### Collision
- Buildings are axis-aligned boxes (`colliders`); poles, palms and fountains are circles (`circles`). `collide()` pushes MVP out of any box or circle he walks into.
- The car checks 6 points around its body (`corners()`); if the next move would hit something it slides along the wall, and if it can't slide it bounces back at 25% speed.
- Traffic cars are moving obstacles: you can't walk through them, and ramming one stops it for 1.5 seconds.

### Controls
- **Keyboard/mouse:** WASD/arrows, Shift, E, F, Space, P, Tab/M. Clicking the screen locks the mouse for camera look.
- **Touch:** touching the left 45% of the screen spawns a joystick under your thumb; the right side drags the camera. Buttons: ACT, CAR, BRAKE, SHOOT, PHONE. Detected with `matchMedia('(pointer: coarse)')`.

### Sound
All sound is synthesized live with the Web Audio API (no audio files): shutter, cash register, phone ring, door, crash, win and fail jingles, and an engine (a filtered sawtooth wave whose pitch rises with speed). Audio starts on your first tap or keypress, because browsers require that.

## 4. The city (`world/lib/district.js`)

`buildDistrict(scene)` builds everything and returns the data the game needs:

| Returned | What it is |
|---|---|
| `colliders`, `circles` | Walls and round obstacles for collision |
| `pois` | Interactive places: `casino`, `velvet`, `studio`, `room12`, `poolspot` |
| `zones` | Named areas for the zone banner |
| `NPC` | Where each character stands (Ruby, Tony, Dee, Editor, Landlord, Bouncer, red carpet...) |
| `walks` | Sidewalk paths for pedestrians |
| `signals` | The traffic light heads, so traffic can change their colors |
| `myCarSpot`, `parked` | Your car's start spot and the parked cars |
| `inBounds(x, z)` | Is this point inside the playable area (barricades at the edges) |
| `premiere` | The red carpet + step-and-repeat group, shown only for the finale |
| `update(t)` | Animates the spinning crown, chasing bulbs, flickering neon |

How it's built:
- **Ground:** one big asphalt plane with a wet, puddled texture; four raised sidewalk blocks with curbs; lane dashes, crosswalks and stop lines drawn with `InstancedMesh` (thousands of copies in one draw call).
- **Buildings:** `building(x0, x1, z0, z1, height, kind, trim)` makes a box with a generated window texture (`warm`, `cool` or `casino` style, with some windows lit) and optional neon trim, and registers a collider.
- **Signs:** text is drawn onto a canvas and used as a glowing texture (`signMesh`, `textTex`).
- **Landmarks:** Crown Casino (104 m tower, rotating crown, bulb-lit porte-cochère, fountain), The Velvet Room, Lens & Light, Scarlet Lounge, Desert Rose Motel and pool, MVP Studios, Chapel of Love, Diamond Diner, plus about 45 filler storefronts along the extended strip.

## 5. Life on the street (`world/lib/npcs.js`)

### Cars (`carModel`)
A car's side profile is drawn as a 2D shape and extruded into 3D, with a glass cabin, clearcoat paint, glowing head/tail lights and four wheels that spin with speed. Your car is red with an MVP plate.

### Traffic (`Traffic` class)
- 4 lanes (2 on the boulevard, 2 on Fremont), 34 cars in total. Each car has a position along its lane and a speed.
- **Traffic lights** run on a 30-second cycle: the boulevard is green for 0–14 s and yellow for 14–17 s; Fremont is green for 17–27 s and yellow for 27–30 s.
- Each frame a car picks a **target speed**, its normal cruising speed (11–15 m/s), lowered when:
  - the light is red or yellow and it's within 30 m of the stop line,
  - another car is less than 12 m ahead,
  - you (or a chase car) are standing in the lane ahead.
- It brakes quickly (9 m/s²) and speeds up gently (3 m/s²). Cars that reach the end of a lane wrap around to the start.

### Pedestrians (`Pedestrians` class)
About 30 simple people (capsule bodies, random skin, hair and clothes) walk back and forth along sidewalk paths. They stop and step aside when you're in their way, and jump out of the way, or turn around, when your car comes at them above 3 m/s.

## 6. Driving and chases (`world/lib/car.js`)

### Your car (`PlayerCar`)
| Thing | Value |
|---|---|
| Acceleration | 9.5 m/s² (22 when switching from reverse) |
| Braking | 20 m/s²; handbrake 24 m/s² |
| Coasting slowdown | 3.2 m/s² |
| Top speed | 32 m/s (≈72 mph), +4 m/s per Engine Tune level |
| Reverse limit | 9 m/s |
| Steering | Smoothed; weaker at low speed, eases off at high speed; the handbrake tightens the turn |

The speedometer shows `speed × 2.237` (m/s → mph).

### Getaway cars (`Chaser`)
- The road network is 5 points: the Center crossing and the North, South, East and West ends.
- The chaser drives in the right-hand lane toward its next point. At the crossing it chooses the exit **farthest from you**, with some randomness so it isn't predictable.
- **Ramming:** if your car gets within 4.2 m, damage = `10 + min(40, closing speed × 1.4)`. There's a 0.6 s cooldown between hits, your car slows by 45%, and both cars get pushed apart.
- Once its health hits 0 it coasts to a stop and you win. If you stay more than 230 m away for 8 seconds, it escapes and the mission fails.

## 7. Characters (`hd-demo/lib/characters.js`)

### Building a person: `makeHero(look)`
Each character is built from a **look** object, for example Ruby:
```js
{ skin: '#b07a52', hair: 'afro', hairC: '#9e1018', outfit: 'two', color: '#d0121e', beret: true, hoops: true, tattoo: true, lips: '#9a0e1a', nails: '#c40f1c' }
```
- **Body:** lathe-turned torso and limbs (smooth shapes like a pottery wheel makes), separate female and male proportions. The torso texture is **painted on a canvas** in code: outfit, MVP logo, buckle, fine-line tattoos, fabric noise.
- **Head:** a deformed sphere with eyes, brows, lips and nose; hair styles `afro`, `braids`, `long`, `bob`, `bun` (anything else gets a close crop); optional beard, beret with gold badge, hoop earrings.
- **Outfits:** `suit` (MVP, Tony), `two` (Ruby's bandeau and tutu), `gown` (Nova), `jump` (Jade), `dress`, `casual`.
- **Props:** `makeDSLR()` builds MVP's camera; `updProps()` keeps it in his hands.
- **Skeleton (joints):** `hips`, `spine`, `head`, shoulders and elbows (`shL/elL/shR/elR`), hips and knees (`hpL/knL/hpR/knR`).

### Animation
- `setPose(rig, pose, blend)` eases each joint toward a target rotation. Poses are simple tables, for example `{ shR: [0, 0, -2.75], elR: [0, 0, -1.4], ... }` for "arm up."
- `walkPose()` makes the walk and run cycles.
- `POSES` is the list of 7 model poses (Classic, Hand on hip, Arm up, Three-quarter turn, Hands on hips, Beret tilt, Stride). `HOLD` is MVP holding his camera.
- In `main.js`, `DANCE(t)` is the club dance; models rotate through poses every 3 seconds, and `n.peak` marks the best moment to shoot.

### Talent (`TALENT`)
| ID | Name | Age | Stars | Day rate | Likes | Unlock |
|---|---|---|---|---|---|---|
| ruby | Ruby Monroe | 26 | 3 | $600 | neon, playful | Mission 1 |
| nova | Nova Starr | 24 | 3 | $700 | warm, romantic | Mission 4 |
| jade | Jade Rivers | 31 | 5 | $1,500 | cool, dramatic | Mission 6 |
| coco | Coco Bellamy | 28 | 2 | $400 | warm, playful | Mission 7 or 25 rep |
| lex | Alexis "Lex" Vaughn | 29 | 4 | $1,100 | neon, dramatic | 45 rep + 2 released films |

### Spring physics (`hd-demo/lib/springs.js`)
- Every springy part (hair, skirt panels, earrings, chest on imported models) is treated as a small weight on a spring. Each frame it lags behind the body's movement, then pulls back toward its resting direction (a method called *verlet integration*).
- Four kinds have tuned settings, blended between "Natural" and "Xtreme" by `springs.amount` (0–1): `breast`, `hair`, `skirt`, `ear`. Each has a spring strength, drag, gravity and a maximum swing angle.
- `scan(model)` **finds spring bones automatically** in imported `.glb` models by name (anything containing "breast", "hair", "skirt", "earring" and so on), so Character Creator 4 models work with no setup.

## 8. Missions (`world/lib/story.js` + `main.js`)

### How a mission is written
Missions are **data**, not code. Each one is a list of steps:

| Step type | What the player does | Example |
|---|---|---|
| `goto` | Reach a place (optionally with a `time` limit) | `{ t: 'goto', to: 'editor', time: 75 }` |
| `enter` | Go into an interior | `{ t: 'enter', scene: 'club' }` |
| `shoot` | Take N scored photos of certain people | `{ t: 'shoot', scene: 'club', subjects: ['ruby'], shots: 4 }` |
| `chase` | Ram a getaway car until its health is gone | `{ t: 'chase', hp: 140, speed: 22, spawn: {...} }` |
| `buy` | Pay for something | `{ t: 'buy', cost: 3500 }` |
| `produce` | Make a film in the studio | `{ t: 'produce' }` |

Each mission also has a `giver` (who starts it), `intro` and `outro` dialogue, and a `reward` (`cash`, `rep`, and optionally `sign`, a performer who joins your roster).

**To add a mission**, add an object to `STORY` in `story.js`. The runner (`startMission → nextStep → completeMission / failMission`) handles the rest.

### Where characters stand: `placement(id)`
One function decides, for every named character, which scene they're in, where, and what they're doing, based on story progress. For example, Ruby waits outside the club before mission 1, dances on the club stage after it, and poses on the red carpet during the finale. Changing the story only means editing this function.

### Gigs
`makeGig()` creates a random freelance job: a place from `GIG_SPOTS`, a name from `FREELANCE`, a look from `FREE_LOOKS`, pay = `$250 + 12 × rep + up to $200`, and a 40% chance it's a 90-second rush job. Three new gigs appear each in-game day.

## 9. Photography scoring (`scoreShot` in `main.js`)

When you press SHOOT during a photo job:
1. The frame is captured as a JPEG (it appears in the strip at the bottom of the screen).
2. For each subject, the game projects their head position onto the screen.
3. **Composition (45%):** how close the face is to one of the four rule-of-thirds points.
4. **Framing (20%):** how much of the frame's height the person fills (35%–120% is ideal).
5. **Timing (35%):** whether they're at the peak of a pose or dance beat.
6. **Gear bonus:** `(gimbal + lens levels) × 4 + lighting kit level × 3`.

`score = (composition × 0.45 + framing × 0.20 + timing × 0.35) × 100 + gear bonus`, capped at 100.

Grades: **A+** 88+, **A** 78+, **B** 66+, **C** 52+, **D** below. The contact sheet averages the set: an A average pays `$200 + 4 × rep` and +2 rep; a B average pays $80.

## 10. The business (`main.js`)

### Money and progress
The save holds:
```js
{ cash: 250, rep: 0, story: 0, studio: false, roster: [], gear: { stab, lens, light, ride },
  releases: [], day: 1, minute: 1420, lastProduce: 0, shots: 0, introDone: false, x, z }
```
`story` is the number of story missions completed (0–8); it also sets your **rung**.

### The climb (`RUNGS`)
| Missions done | Rung |
|---|---|
| 0 | Hired Lens |
| 1–2 | Vendor |
| 3 | Runner |
| 4 | Byline |
| 5 | Landlord |
| 6 | Producer |
| 7 | Distributor |
| 8 | Mogul |

It shows next to your rep in the HUD, and a "Promoted" line appears on the mission-complete card when it changes.

### Studio productions
1. Cast up to 2 performers (pay their day rates), pick a set and a crew size.
2. Make three director's calls: lighting (warm / cool / neon), mood (playful / romantic / dramatic), camera (handheld / dolly / locked-off). Each performer's attitude note is shown on the first call.
3. **Quality** =
   - average of `stars × 12` across the cast,
   - +8 for a two-person cast,
   - + the set's bonus (Stage A 6, Pool 9, Velvet Room 12, Penthouse 15),
   - + `lighting kit level × 5`,
   - +7 for each performer whose favorite lighting you chose, +7 for each whose favorite mood you chose,
   - + camera (dolly 5, handheld 3, locked-off 1),
   - then × crew multiplier (Lean 0.9, Standard 1.1, Premium 1.35), clamped to 10–100.
4. **Opening sales** = `quality × (25 + rep) × 2.2`. **Royalties** = 8% of that, every in-game day.
5. The wrap message depends on quality (75+ "The scene works", 50+ "Solid, sellable", below that "opens soft and dies at the box office").

One production per in-game day (except the story's first feature).

### Bootlegs
While mission 7 (Bootleg Boulevard) is your next mission, `bootleg()` is true and your daily royalties are **halved**. The Catalog screen and the daily payout message both say so.

## 12. Real characters (the HD pipeline)

1. Build the character in **Character Creator 4** (or Daz 3D); export FBX into `uploads/`.
2. Run `tools/optimize-character.sh uploads/ruby.fbx assets/characters/ruby.glb`. It converts FBX → glTF (`fbx2gltf`), then compresses the meshes (meshopt) and textures (WebP) with `gltf-transform`, usually cutting the size by 80–90%.
3. `hd-demo/` loads `assets/characters/mvp.glb` and `ruby.glb` automatically, or you can drag a `.glb` onto the page. Its animations play, and `SpringSystem.scan()` wires up hair, skirt and chest physics by bone name.

The world game still uses the code-built characters; swapping the real models in there is the next step on the roadmap.

## 12b. How the city is made to look real

| Effect | File | How it works |
|---|---|---|
| **Building facades** | `architecture.js` → `facadeMaterial()` | One full PBR texture set per style (glass office, gold casino glass, stucco hotel, brick), each covering 8 bays × 8 floors at real 3.5 m spacing: color, glowing windows (rooms with ceiling lights, curtains, blinds, silhouettes), roughness (glass is mirror-smooth, walls are rough) and a normal map for frames and sills. Every building gets its own offset and light tint so no two look alike. |
| **Street light on walls** | `architecture.js` → `addStreetWash()` | A shader tweak adds warm light spilling up from the street, fading with height, plus a faint sky glow on upper floors. |
| **Tower shapes and roofs** | `district.js` → `building()` + `RoofKit` | Buildings over 40 m step back above a podium. Every roof gets a parapet, stair/elevator rooms, HVAC units, water tanks, antennas and blinking red aircraft lights (all instanced, a few draw calls total). |
| **Night sky** | `sky.js` → `makeNightSky()` | A shader dome: navy zenith, orange/magenta light pollution at the horizon, slowly drifting clouds lit from below by the city, and a moon with a halo lined up with the shadow light. |
| **Wet streets** | `reflect.js` → `WetReflections` | Each frame the city is drawn again from a camera mirrored under the road (at 1/2 or 1/3 resolution). Road, sidewalk and puddle materials sample that image, smeared vertically like real wet asphalt, stronger at grazing angles and where a world-space puddle mask says there's standing water. Characters and pedestrians are on layer 1, which the reflection pass skips to save time. |
| **Vegas signage** | `strip.js` | Four animated LED screens (MVP Media, Crown jackpot reels, Scarlet Lounge, Vegas Nightlife Weekly) drawn to canvases at 12 fps with an LED pixel grid; chasing-bulb marquees; the Crown pylon sign; a glass skybridge over the boulevard; parking meters, trash cans, news boxes and a bus shelter; median shrubs and uplit palms. |
| **Cars** | `npcs.js` → `carModel()` | Headlight and taillight flares (they bloom and show up in the wet road) and taxis with roof signs (about 28% of traffic). |

**Graphics presets** (the button in the corner):
- **Performance** turns off shadows, bloom, color grading and reflections.
- **Balanced** adds them back, with reflections at 1/3 resolution on desktop. On phones, Balanced skips reflections.
- **Cinematic** draws reflections at 1/2 resolution, at a higher pixel ratio.

**Cost** (desktop, Cinematic, at the studio): about 1,130 draw calls for the main view plus about 540 for the reflection pass.

## 13. Testing and debugging

- `window.__world` in the browser console exposes the game state: `__world.save` (edit cash, story, etc.), `__world.startMission(__world.STORY[3], 'story')`, `__world.enter('club')`, `__world.update(0.033)` to step one frame.
- Automated checks have been run in headless Chromium (Playwright): mission 1 end to end, driving, a full chase, buying the studio, producing a film, the rung HUD and the Catalog.
- `__world.debugCam = { pos: [x, y, z], look: [x, y, z] }` freezes the camera for screenshots (`null` to release). `__world.probe()` reports draw calls for the main and reflection passes.
- `node tests/demo-flow.cjs` checks the demo mission flow. `tools/check-graphics.cjs` builds the whole city, strip, reflections and sky in Node to catch broken geometry (see GRAPHICS.md for how to run it).
- **Reset your save:** in the console, `localStorage.removeItem('mvp_world_v2')` and reload.
